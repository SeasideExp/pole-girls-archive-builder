# POLE GIRLS ARCHIVE BUILDER (Ver.0.51b)

> **最終更新: 2026年11月20日 ／ 最新バージョン: Ver.0.51b**  
> ※ 更新履歴は [**`CHANGELOG.md`**](./CHANGELOG.md) をご覧ください。

キャラクター図鑑・紹介ページをノーコードで作成し、単一HTMLファイルとして書き出せるWeb制作ツールです。

---

## 📖 1. 概要

キャラクター・カテゴリ・デザインを設定するだけで、検索・絞り込み機能と詳細モーダルを備えたアーカイブページを作成し、そのまま公開用HTMLとして出力できます。

---

## ✨ 2. 主な機能

- **キャラ編集**: アイコン・立ち絵（2枚切替／サイズ調整）・紹介文・スペック・テーマカラーを登録。画像は `img/` 相対パス推奨（Base64埋め込みも可）。
- **カテゴリ・絞り込み**: 大／小カテゴリの整理、追従フィルターでのキーワード検索・OR/AND・昇順/降順・表示密度（標準／アイコン／リスト）切替に対応。
- **デザイン設定**: タイトル・アクセントカラー・背景パターン・見出し書式などを即時プレビュー。
- **書き出し・保存**: 外部依存なしの単一HTML書き出し、JSON設定保存、JSON／書き出し済みHTMLの再読込に対応。

> [!WARNING]
> **データのバックアップについて**: 作業内容はブラウザ内に自動保存されますが、閲覧データの消去等で失われる恐れがあります。こまめに **「設定保存(JSON)」** で保存してください。

---

## 🚀 3. 動作方法

Webサーバーは不要です。**[`index.html`](./index.html) をブラウザで直接開くだけ（`file://`）**で動作します。

---

## 📁 4. 構成

```text
pole-girls-archive/
├── index.html           # エディタUI・スクリプト読込
├── README.md            # プロジェクト解説
├── CHANGELOG.md         # 変更履歴
├── AGENTS.md            # 開発ガイドライン
├── img/                 # キャラクター画像フォルダ
└── js/
    ├── templates.js     # 初期データ・定数
    ├── viewer-styles.js # ビューア用CSS
    ├── viewer.js        # 一覧・検索・詳細モーダル描画
    ├── state.js         # 状態管理・自動保存
    ├── io.js            # HTML書き出し・JSON/HTML読込
    ├── editor.js        # 編集サイドバーUI
    └── main.js          # モジュール統合・初期化
```
